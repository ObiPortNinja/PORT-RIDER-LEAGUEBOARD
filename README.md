# PORT Rider League

A mobile web app for PORT riders at the Clerkenwell hub.

- Leaderboards for the Doorstep (D2D) and Lockers (OOH) divisions, last 28 days
- Points for parcels delivered, perfect shifts, early check-ins, leaving on time and leading training shifts
- Levels from Rookie to Specialist, badges and milestones
- Updated every weekday before 09:00 and again after the evening de-brief

Open the link on your phone and choose "Add to Home Screen" to install it.

Shows first name and initial only. No pay information is included.
